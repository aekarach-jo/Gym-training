# FORM. — Gym Training ส่วนตัว

เว็บฝึกออกกำลังกายส่วนตัวด้วย Next.js: แผนฝึกสำเร็จรูป 3 แบบและแผนส่วนตัวหลายแผน, ท่าบอดี้เวต 9 ท่า, ภาพการ์ตูนสาธิต, กล้องช่วยนับและจับเวลาทุกท่า, ชาเลนจ์รายวัน, สถิติการฝึก, กราฟติดตามน้ำหนัก และสำรองข้อมูลเป็นไฟล์ JSON

## รันบนเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## ตรวจสอบก่อน deploy

```bash
npm run lint
npm run build
```

Deploy โครงการ Next.js นี้บน Vercel ได้โดยใช้ค่าเริ่มต้น ไม่ต้องตั้ง environment variable หรือฐานข้อมูล เว็บจะได้ HTTPS จาก Vercel โดยอัตโนมัติ ส่วนกล้องต้องเปิดผ่าน HTTPS หรือ localhost และผู้ใช้ต้องอนุญาตสิทธิ์กล้องในเบราว์เซอร์

## ข้อมูลและกล้อง

- ประวัติการฝึก แผนที่เลือก เป้าหมายชาเลนจ์ และน้ำหนักเก็บใน localStorage ของเบราว์เซอร์นี้เท่านั้น
- หน้า **แผนฝึก → สร้างแผนใหม่** ใช้เลือกวันฝึก จัดท่าตามลำดับ ปรับเซต เป้าหมายต่อเซต เวลาพัก และเขียนโน้ตเฉพาะท่า สร้าง แก้ไข คัดลอก หรือลบแผนได้ หน้า **วันนี้** และกล้องใช้ค่าของแผนที่เลือก
- หน้า **ประวัติ** แสดงสถิติฝึกต่อเนื่อง เป้าหมายรายสัปดาห์ ปฏิทิน 30 วัน ผลงานสูงสุด แนวโน้มรายท่า และกรองบันทึกตามท่า ช่วงเวลา หรือวิธีบันทึก ลบเซตผิดแล้วกด **เลิกทำ** ได้ภายใน 8 วินาที
- ข้อมูลรุ่นเดิมจะถูกย้ายไปโครงสร้างใหม่อัตโนมัติเมื่อเปิดเว็บ; ไฟล์สำรองรุ่นเดิมยังนำเข้าได้
- ใช้เมนู **ตั้งค่า → ส่งออกข้อมูล** เพื่อสำรอง และ **นำเข้าข้อมูล** เพื่อกู้คืนหรือย้ายเครื่อง
- กล้องและการประมวลผลท่าทำบนอุปกรณ์ด้วย MediaPipe; เว็บไม่บันทึกวิดีโอ
- ตัวช่วยกล้องรองรับทั้ง 9 ท่า โดยหน้าฝึกระบุมุมกล้องที่ควรวาง ท่าวิดพื้น สควอต ลันจ์ และสะพานยกสะโพกใช้มุมด้านข้าง; กระโดดตบ ยกเข่าสูง และแพลงก์ข้างใช้มุมด้านหน้า
- เมื่อกล้องนับครบเป้าหมายของเซต ระบบบันทึกผลอัตโนมัติและแสดงวงกลมนับถอยหลังพักตามเวลาของท่านั้น ระหว่างพักกล้องหยุดนับชั่วคราว แล้วเริ่มเซตถัดไปเมื่อหมดเวลา (หรือกดข้าม)
- กล้องเล่นไฟล์เสียงสั้นเมื่อเปิดกล้องเพื่อเตรียมเสียงบน Safari และเมื่อบันทึกจำนวนครั้งหรือวินาทีสำเร็จ มีปุ่มลองเสียงพร้อมแจ้งผลการเล่นและสวิตช์ปิดเสียงในหน้ากล้อง; บน Safari ของ iPhone ระบบขอใช้โหมดเสียงสำหรับการเล่นสื่อเมื่อเบราว์เซอร์รองรับ
- ท่าลันจ์และแพลงก์ข้างบันทึกแยกซ้าย–ขวา; หากต้องการกำหนดจำนวนเองให้สลับไปโหมดบันทึกเอง
- การประเมินจากกล้องอาจคลาดเคลื่อนตามแสง มุม และการบังของร่างกาย และยังไม่ผ่านการทดสอบด้วยผู้ใช้งานจริงทุกท่า
- โมเดลและไฟล์ WASM อยู่ใน `public/` เพื่อให้ระบบกล้องไม่ต้องพึ่ง CDN ขณะใช้งาน

ภาพการ์ตูนสาธิตใน `public/exercises/` สร้างขึ้นใหม่สำหรับโครงการนี้
